## 🔍 JAX Backend 的真实要求

### 源码证据

查看 `jax/_src/xla_bridge.py:226`：

```python
BackendFactory = Callable[[], Union[xla_client.Client, None]]
```

**关键发现：** Backend 工厂必须返回 `xla_client.Client` 对象！

这意味着：
- ❌ 简单的 Python 类**不能**作为真正的 backend
- ❌ 不能直接执行 jit、pmap 等操作
- ✅ 只能模拟接口（device_count, devices 等）

---

### 方案 2: 借用 JAX 现有设备 ⭐⭐⭐

**代码：**
```python
import jax
from jax import pmap

# 不注册新 backend，直接使用 JAX 设备
devices = jax.devices()  # CPU 或 GPU

# NPU 模拟层（软件）
class NPUSimulator:
    def quantize_int8(self, x):
        scale = jnp.max(jnp.abs(x)) / 127.0
        return jnp.round(x / scale).astype(jnp.int8).astype(jnp.float32) * scale
    
    def npu_matmul(self, a, b):
        return jnp.matmul(self.quantize_int8(a), self.quantize_int8(b))

npu = NPUSimulator()

# 直接使用原生 JAX API
@pmap
def compute(x, w):
    return npu.npu_matmul(x, w)  # NPU 特性 + JAX 计算

# 执行
x = jnp.ones((4, 256, 512))
w = jnp.ones((4, 512, 256))
result = compute(x, w)  # ← 真的能算！
```

**真实能力：**
- ✅ **可以执行 jit**
- ✅ **可以执行 pmap**
- ✅ **可以使用 Sharding API**
- ✅ **可以使用 shard_map**
- ✅ **可以自动微分**
- ✅ **可以添加 NPU 特性**

**原因：** 使用的是真正的 JAX 设备（xla_client.Client）

**适用：** 实际开发、测试、训练

import jax
from jax import pmap, jit

# 1. 使用 JAX 设备作为虚拟 NPU

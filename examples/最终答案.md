### Q4: 可以复用原生 shard API 吗？

**A:** **可以 - 但只有方案 2 可以**

```python
# 方案 2 - 完全可以使用原生 API
from jax.sharding import Mesh, NamedSharding, PartitionSpec as P
from jax.experimental.shard_map import shard_map

# 直接使用！
devices = jax.devices()
mesh = Mesh(np.array(devices[:4]), ('x',))

@shard_map(mesh=mesh, in_specs=P('x', None), out_specs=P('x', None))
def compute(x):
    return x * 2

# ✅ 完全可以执行！
```

## 🔑 核心技术真相

### JAX Backend 要求（源码证据）

```python
# jax/_src/xla_bridge.py:226
BackendFactory = Callable[[], Union[xla_client.Client, None]]
```

Backend 必须返回 `xla_client.Client`，这需要：
1. C++ 实现的 PJRT 插件，或
2. JAX 内置的 CPU/GPU/TPU client

**结论：** 简单 Python 类 **不是** 真正的 backend

## 💡 推荐方案（方案 2）

### 架构

```
用户代码（JAX API：pmap, Sharding, jit）
    ↓
NPU 模拟器（量化、专用算子）← 你写的
    ↓
JAX 真实设备（CPU/GPU）← 已有的
```

### 核心代码

```python
import jax
import jax.numpy as jnp
from jax import pmap, jit
from jax.sharding import Mesh, NamedSharding, PartitionSpec as P
import numpy as np

# 1. NPU 模拟器（你的代码）
class NPUSimulator:
    def quantize_int8(self, x):
        scale = jnp.max(jnp.abs(x)) / 127.0
        quantized = jnp.round(x / scale).astype(jnp.int8)
        return quantized.astype(jnp.float32) * scale
    
    def npu_matmul(self, a, b):
        return jnp.matmul(self.quantize_int8(a), self.quantize_int8(b))

npu = NPUSimulator()

# 2. 使用 JAX 设备作为虚拟 NPU
devices = jax.devices()  # 这些就是虚拟 NPU
print(f"虚拟 NPU: {devices}")

# 3. 直接使用所有 JAX 原生 API ✅

# pmap - 原生 API
@pmap
def pmap_compute(x, w):
    return npu.npu_matmul(x, w)

# Sharding - 原生 API
mesh = Mesh(np.array(devices[:4]), ('x',))
sharding = NamedSharding(mesh, P('x', None))

@jit
def sharded_compute(a, b):
    return npu.npu_matmul(a, b)

A = jnp.ones((1024, 512))
A_sharded = jax.device_put(A, sharding)
result = sharded_compute(A_sharded, A_sharded.T)

# shard_map - 原生 API
from jax.experimental.shard_map import shard_map

@shard_map(mesh=mesh, in_specs=P('x', None), out_specs=P('x', None))
def shard_map_compute(a):
    return npu.npu_matmul(a, a.T)

result = shard_map_compute(A)

# ✅ 所有原生 API 都能用！
```

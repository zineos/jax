# 模拟 GPU/NPU 集群完整指南

## 🎯 目标

在没有真实硬件的情况下，模拟 **GPU 集群** 或 **自定义 NPU 集群**，用于：
- ✅ 开发和测试分布式训练代码
- ✅ 验证多节点通信逻辑
- ✅ CI/CD 自动化测试
- ✅ 学习和演示分布式计算

## 💡 使用场景

### 场景 1: 在 JAX 中使用虚拟 GPU 集群

```python
import jax
import jax.numpy as jnp
from examples.simulate_gpu_cluster import register_gpu_cluster_backend

# 1. 注册虚拟 GPU 集群
register_gpu_cluster_backend(
    name="test_cluster",
    num_nodes=2,           # 2 个节点
    gpus_per_node=8,       # 每节点 8 个 GPU
    gpu_model="A100-80GB",
    platform="cuda"
)

# 2. 获取 backend
from jax.extend import backend
gpu_cluster = backend.get_backend("test_cluster")

# 3. 查看集群信息
print(f"总 GPU 数: {gpu_cluster.device_count()}")
print(f"本地 GPU 数: {gpu_cluster.local_device_count()}")
print(f"所有设备: {gpu_cluster.devices()}")

# 4. 模拟使用（注意：虚拟 backend 不能真正执行计算）
# 但可以用于测试代码结构和接口
devices = gpu_cluster.local_devices()
print(f"可以在 {len(devices)} 个 GPU 上并行训练")
```

### 模拟设备故障

```python
class FaultyGPUCluster(GPUClusterBackend):
    """模拟设备故障的集群"""
    
    def __init__(self, *args, faulty_devices=None, **kwargs):
        super().__init__(*args, **kwargs)
        self._faulty_devices = faulty_devices or []
    
    def devices(self):
        """返回设备列表，排除故障设备"""
        all_devices = super().devices()
        return [d for d in all_devices if d.id not in self._faulty_devices]
    
    def device_count(self):
        return len(self.devices())

# 使用
cluster = FaultyGPUCluster(
    num_nodes=2,
    gpus_per_node=8,
    faulty_devices=[2, 5, 11]  # GPU 2, 5, 11 故障
)

print(f"可用设备: {cluster.device_count()}/16")  # 13/16
```

## 🧪 测试示例

### 完整的测试工作流

```python
# test_with_virtual_cluster.py
import pytest
from examples.simulate_gpu_cluster import (
    GPUClusterBackend, 
    register_gpu_cluster_backend
)

class TestDistributedTraining:
    @classmethod
    def setup_class(cls):
        """在所有测试前设置虚拟集群"""
        register_gpu_cluster_backend(
            name="test_8gpu",
            num_nodes=1,
            gpus_per_node=8,
            gpu_model="A100"
        )
    
    def test_cluster_configuration(self):
        """测试集群配置"""
        from jax.extend import backend
        cluster = backend.get_backend("test_8gpu")
        
        assert cluster.device_count() == 8
        assert cluster.platform == "cuda"
        assert len(cluster.devices()) == 8
    
    def test_device_allocation(self):
        """测试设备分配"""
        from jax.extend import backend
        cluster = backend.get_backend("test_8gpu")
        
        devices = cluster.devices()
        
        # 验证设备 ID 连续
        device_ids = [d.id for d in devices]
        assert device_ids == list(range(8))
        
        # 验证设备属性
        for device in devices:
            assert device.platform == "cuda"
            assert device.device_kind == "A100"
            assert device.memory_gb == 40
    
    def test_multi_process_simulation(self):
        """测试多进程模拟"""
        # 模拟 2 个进程
        backends = []
        for proc_id in range(2):
            backend = GPUClusterBackend(
                num_nodes=1,
                gpus_per_node=8,
                processes_per_node=2,
                current_process_index=proc_id
            )
            backends.append(backend)
        
        # 每个进程应该看到 4 个设备
        for backend in backends:
            assert backend.local_device_count() == 4
        
        # 总设备数应该是 8
        assert backends[0].device_count() == 8

# 运行测试
if __name__ == "__main__":
    pytest.main([__file__, "-v"])
```

## ⚠️ 限制和注意事项

### 虚拟集群的限制

1. **不能执行实际计算**
   - 虚拟 backend 只提供接口模拟
   - 无法运行 jax.jit 或 jax.pmap
   - 仅用于结构测试和逻辑验证

2. **内存管理**
   - 不会真正分配设备内存
   - 内存相关的错误无法测试

3. **通信模拟**
   - 集合通信（NCCL/HCCS）是模拟的
   - 无法测试真实的网络性能

### 使用建议

✅ **适合用于：**
- 代码结构测试
- 接口验证
- CI/CD 流水线
- 文档和教学
- 快速原型验证

❌ **不适合用于：**
- 性能基准测试
- 实际模型训练
- 精度验证
- 内存优化测试
